# Zereos AI

Zereos is an independent web-based personal AI assistant.

## Architecture
- Python standard-library HTTP server
- Browser chat UI
- Server-side AI provider keys
- Automatic provider fallback
- No provider API key is sent to the browser

## Supported server keys
OPENAI_API_KEY, DEEPSEEK_API_KEY, QWEN_API_KEY, GEMINI_API_KEY, GEMINI_API_KEY2

## Run
`python server.py`
